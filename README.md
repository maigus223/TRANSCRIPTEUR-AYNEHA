# Transcripteur Latin → AYNEHA

**Concepteur et créateur : Mahamadou Issiaka MAIGA (MAIGUS)**

Outil de transcription phonétique du songhay (saisie latin ASCII) vers l'alphabet AYNEHA, écriture originale créée par Mahamadou Issiaka MAIGA (MAIGUS).

## Installation (PWA)

Cette application est une Progressive Web App installable sur écran d'accueil (Android, iOS, ordinateur) une fois hébergée en HTTPS (ex. GitHub Pages).

## Structure

- `index.html` — application principale
- `manifest.json` — configuration d'installation
- `sw.js` — service worker (fonctionnement hors-ligne)
- `icons/` — icônes de l'application
