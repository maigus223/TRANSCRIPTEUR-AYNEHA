Transcripteur AYNEHA

Tapez le songhay en lettres latines : il s'écrit en AYNEHA, de droite à gauche.
Résultat en AYNEHA
Le texte AYNEHA apparaît ici pendant que vous tapez.

Pour WhatsApp / Word : le texte est déjà retourné pour s'afficher de droite à gauche dans les applications qui ne le font pas toutes seules. En ordre normal : pour les logiciels qui gèrent eux-mêmes l'écriture de droite à gauche (comme ce site).

Installer l'application
Ajoutez le transcripteur sur votre écran d'accueil, utilisable hors connexion.
Règles appliquées : voyelle + n (simple) = nasalisation · lettre doublée = gémination · consonne suivie d'une autre consonne ou en fin de mot = muette (nue) · sh / š → Σ · c / tch → TΣ · dj / di + voyelle → DJ · ng (hors contexte vocalique) ou ŋ → Ŋ · voyelle + ng → voyelle nasalisée + g · gn / ny / ni + voyelle → Ɲ (sauf « nii » → N + I double) · v → w · ɛ, ɔ saisis directement (ouvert), è / ê → ɛ, ô → ɔ · virgule et point-virgule → glyphes dédiés · point d'interrogation en miroir · autre ponctuation conservée.
